# Coffee Shop

## Descrição

Projeto de uma página para a Coffee Shop da biblioteca Triple Peaks. A página apresenta informações sobre a cafeteria, receitas em vídeo, um formulário para reserva de mesas e links para as redes sociais.

## Tecnologias e técnicas utilizadas

- HTML5 com estrutura semântica
- CSS3
- Metodologia BEM
- Flexbox
- Posicionamento relativo e absoluto
- Formulários HTML
- Vídeos incorporados com iframe
- Google Fonts
- Git e GitHub

## Planos de melhoria

No futuro, pretendo implementar o envio real das reservas para um servidor e adicionar uma versão responsiva para celulares e tablets.
